## 手验过程

mock `sequence` 模式：批内第 i 个 schema 峰落在 logit `i % n`，与 state 无关 → 5 条记录完全同分布。

- `c1`（choice 2 选）：logits `[4, 0]` → `P(a) = e⁴/(e⁴+1) = 0.982013`；mass(c1) = 0.982013。
- `n1`（noul，默认 abstain=true → 3 logits `{yes, no, abstain}`）：峰在 index 0 → `P(yes) = e⁴/(e⁴+2) = 0.964663`；value=true，mass(n1) = 0.964663。
- `path_prob = 0.982013 × 0.964663 = 0.947312`（逐条相同）。
- y = [1, 1, 0, 0, 1]（s3 期望 c1=b 未中；s4 期望 n1=false 未中），accuracy = 0.6 ✓。
- traj_brier = [3×(1−0.947312)² + 2×0.947312²]/5 = (0.008323 + 1.794800)/5 = 0.360625 ≈ 0.360626 ✓（f32 精度）。
- traj_ece = |mean p − acc| = 0.947312 − 0.6 = 0.347312 ✓（全落同一 bin）。
- by_node：c1 置信 0.982013×5，acc 0.8 → ece = 0.182013 ✓；n1 置信 0.964663×5，acc 0.8 → ece = 0.164663 ✓。

## 读数

单跳 node-level ECE ≈ 0.17–0.18（mock 恒定置信度下的期望缺口），trajectory-level ECE = 0.347 ≈ 两者之和量级——
